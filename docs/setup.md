# Setup details

Load id1/pak0.pak, with the complete original PAK set alongside it. The tested profile uses Modern device 773, software 640x400, 60 Hz, and tyrquake_invert_y_axis enabled. Physical Xbox A jumps and confirms menus; B swims down or cancels menus, X swims up, Y runs, LB/RB select weapons and RT fires. L2 is unused by gameplay and reserved for frontend fast-forward. L3/R3 save/load native `id1/tvquick.sav` under the writable frontend save directory; disable generic frontend save-state button bindings as shown in the override. Reset starts a fresh game; R3 can restore the native save afterward. These profiles do not change global hotkeys.
