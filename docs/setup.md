# Setup details

Load id1/pak0.pak, with the complete original PAK set alongside it. The tested profile uses Modern device 773, software 640x400, 60 Hz, and tyrquake_invert_y_axis enabled. The pak0.rmp maps physical Xbox A to jump and disables the L2 jump action because the user's global left trigger activates fast-forward. The profile does not set a global fast-forward binding. Native saves go to the writable Quake save directory.
